# Dataset (not included)

The BRFSS training and test CSVs were provided for the EPFL CS-433 course. They are not redistributed in this public portfolio repository.

If you have the **appropriate access and redistribution permissions**, place the following files here to use the archived preprocessing script:

```text
dataset/
├── x_train.csv
├── y_train.csv
└── x_test.csv
```

Do not commit original survey data, participant-level rows, or generated NumPy arrays.
